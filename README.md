# Путешествия с ИИ-помощником

Демо-проект для хакатона. Интерактивный планировщик путешествий Вы описываете, куда и когда хотите поехать, а ассистент в чате собирает готовый маршрут — с транспортом, отелями.

Проект построен для реализации идей на основе **MCP-сервера Туту**

- **Транспорт.** Перелёты, поезда и автобусы между городами маршрута с учётом пожеланий («поездом», «на ж/д»).
- **Отели.** Варианты проживания с ценами в каждом городе.
- **Карта маршрута.** Весь путь от точки до точки.
